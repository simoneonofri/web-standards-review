# Evaluation

Eval prompts in `evals/prompts.jsonl` cover explicit and implicit invocation, non-trigger cases, mixed-version rejection, normative algorithm extraction, derived-pattern reasoning, catalog update, check application, and incomplete dependency handling.

The rubric scores invocation correctness, traceability, source-versus-inference separation, one-spec scoping, security relevance, pattern quality, check actionability, uncertainty handling, and catalog integrity.
