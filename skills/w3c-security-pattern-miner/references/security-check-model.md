# Security Check Model

A check must be independently actionable. It needs a precise question, applicability, evidence to collect, pass, partial, fail, unknown, and not-applicable criteria, common failure modes, suggested tests, source pattern, provenance, confidence, and maturity.

Scopes are `specification-design`, `implementation-conformance`, and `deployment-operation`. A `fail` requires affirmative contradictory evidence. Missing text is usually `unknown`, not fail.
