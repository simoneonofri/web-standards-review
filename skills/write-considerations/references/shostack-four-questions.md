# From the Shostack four questions to specification prose

Use Shostack's four questions to organize evidence, not to copy passages or deliver an unreviewed threat list.

1. What are we working on? Use the accepted model and exact source version to state scope, actors, boundaries and assets.
2. What can go wrong? Use explicit threats, implicitly protected threats, and distinct additional elicitation, with concrete bad events.
3. What are we going to do about it? Explain the documented or proposed ERTA responses, enforcement actor and remaining harm.
4. Did we do a good enough job? Include untested assumptions, boundary conditions, remaining threats and open issue decisions honestly.

A published threat model can be useful to reviewers but it does not replace self-contained Security and Privacy Considerations in the actual specification. Avoid publishing private analysis or overstating what has been tested.
